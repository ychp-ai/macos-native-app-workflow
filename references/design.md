# design · 原生 UI 设计

## 执行与交付

读取目标场景、品牌和既有界面。按需使用 build-macos-apps:swiftui-patterns 与 ui-ux-pro-max，先确定窗口、侧栏、详情、工具栏、菜单和设置的职责，再确定系统控件、排版、间距和各状态。优先符合桌面键盘、焦点、鼠标和窗口缩放习惯；以现有 AppKit 工程为基础时保留其实现方式。

需要玻璃材质且 SDK/部署目标支持时读取 build-macos-apps:liquid-glass；使用新 API 前核实可用版本并设计回退。不要为视觉效果擅自提高最低系统版本。

交付 ui-spec.md，包含布局、尺寸变化、亮暗外观、焦点与快捷键、加载/空/错误状态。默认交付设计；明确要求原型或设计并实现时完成指定呈现层，保留既有数据与业务合同。
