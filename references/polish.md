# polish · 界面打磨

## 执行与交付

从用户要求确定只评审或直接修改；“优化/调整”默认执行范围内修改，不重复确认。按需使用 impeccable、ui-ux-pro-max 和 build-macos-apps:swiftui-patterns，检查原生控件、对齐、信息层级、亮暗模式、快捷键提示、可访问性标签和反馈文案。

保持品牌、信息结构和业务功能，集中修复可观察问题。需要玻璃效果调整时读取 build-macos-apps:liquid-glass 并核对可用性。完成一次集中检查和修复，必要时一次确认，避免无限审美迭代。交付 ui-review.md 或现有记录，区分真实观察和代码推断。
